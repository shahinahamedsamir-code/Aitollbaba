Privacy. This page has no upload endpoint. Every file you add is processed by JavaScript on your own device and discarded when the tab closes. No account, no cookies from us, no copy of your file kept anywhere. A page counter records visits to the site, never a file. Full privacy policy.

Use it honestly. Stripping metadata is a privacy measure. It does not make an AI-generated image undetectable and it is not a way around a platform’s disclosure rules. Where you are required to label AI-generated content, label it.
